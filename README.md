# Control de Energía

Utilidad de Windows en Python que permite gestionar el plan de energía del equipo desde una interfaz gráfica sencilla.

## Uso

Ejecuta `Control_Energia.pyw` con doble clic. También puedes generar un ejecutable con:

```powershell
pyinstaller --noconfirm --onefile --windowed Control_Energia.pyw
```

## Requisitos

- Python 3.x en Windows

## Aviso

Esta herramienta modifica ajustes de energía del sistema. Revisa el código antes de ejecutarla y guarda tu configuración original.
